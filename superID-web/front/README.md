# Front-End React App

Este projeto foi iniciado com [Create React App](https://github.com/facebook/create-react-app).

## Scripts Disponíveis

No diretório do projeto, você pode rodar:

### `npm start`

Inicia o app em modo de desenvolvimento.  
Abra [http://localhost:3000](http://localhost:3000) para visualizar no navegador.

### `npm run build`

Gera uma versão otimizada do app para produção na pasta `build`.

### `Ctrl + C`

Para abortar a execução do código em qualquer momento.

## Observações

- Use `npm run eject` **apenas se for necessário customizar configurações como Webpack ou Babel**. Essa ação é permanente.
- Para mais detalhes sobre React, acesse a [documentação oficial](https://reactjs.org/).
